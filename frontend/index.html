Postavljanje Google credentials
  1. Idi na console.cloud.google.com
  2. Kreiraj novi projekt ili koristi postojeći
  3. Idi na APIs & Services → Enable APIs → uključi Gmail API i Google Drive API
  4. Idi na Credentials → Create Credentials → OAuth 2.0 Client ID
  5. Application type: Desktop app
  6. Preuzmi JSON → preimenuj u credentials.json
  7. Stavi fajl u: spedicija-app/credentials.json
  8. Restartaj app → browser će se otvoriti za Google login (jednom)

Kako radi feedback petlja
  1. Claude AI predlaže tarifni broj za svaku stavku
  2. Agent provjeri i ispravi po potrebi u tabeli stavki
  3. Agent klikne Potvrdi pored tarifnog broja — sistem pamti mapiranje
  4. Sljedeći put ista ili slična roba → sistem koristi potvrdenu korekciju AUTOMATSKI (bez AI poziva)
  5. Što više korekcija, to manje AI grešaka — sistem uči s vremenom
